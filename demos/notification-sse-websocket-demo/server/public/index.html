Mở 2 tab trình duyệt với cùng User ID để thấy notification tới cả hai cùng lúc. Thử tắt mạng (DevTools → Network → Offline) rồi bật lại: SSE tự reconnect (built-in của EventSource), WebSocket ở đây tự reconnect bằng logic tay (backoff) viết trong app.js. Cột "latency" là thời gian từ lúc server publish tới lúc client render (đồng hồ client/server có thể lệch nhẹ). Nếu chạy docker compose up, có 2 instance server (:3000 và :3001) chia sẻ chung Redis — mở mỗi cổng ở một tab để xem badge instance khác nhau, rồi xem log docker compose logs để thấy notification chỉ được route tới đúng instance đang giữ kết nối, instance còn lại không nhận gì cả.
